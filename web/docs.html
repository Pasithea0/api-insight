How to send events to API Insight.
Sending events
POST request batches to /v1/events with a Bearer API key.

Use an API key from Settings. Send a POST to your API Insight base URL with path /v1/events, header Authorization: Bearer PROJECT_API_KEY, and Content-Type: application/json.

Request body: 

{
  "events": [
    {
      "path": "/api/users",
      "method": "GET",
      "status": 200,
      "duration_ms": 45,
      "timestamp": "2024-01-28T12:00:00Z",
      "remote_ip": "192.0.2.1",
      "attributes": {
        "env": "production",
        "region": "us-east-1"
      }
    }
  ]
}

The fields shown are required: path, duration_ms, and optionally method, status, timestamp, remote_ip. Any additional data can be added in the attributes block as key/value JSON (e.g. env, region).

Public API access
Expose selected aggregated data with a separate read-only public API key.

Each project can enable a separate public API key for read-only public endpoints. This key is different from the write key used for /v1/events, and can be rotated independently.

All endpoints under /v1/public/* are secured with that public API key.

Currently available public endpoint: 

GET /v1/public/top-endpoints?public_key=PROJECT_PUBLIC_KEY&range=7d&status=error&count=10

Query parameters:

  • public_key or key: the public API key for the project
  • range: compact range like 24h or 7d (defaults to 1d)
  • status: all, success, or error
  • count: number of routes to return, up to 100 (defaults to 20)

Public endpoints are intended for safe aggregated data only. The current top-endpoints endpoint returns route counts and status breakdowns, and does not expose IP addresses, user agents, referers, or individual request data.

Example: 

{
  "project": "payments-api",
  "range": "7d",
  "status": "error",
  "count": 10,
  "routes": [
    {
      "route": "/api/orders/submit",
      "count": 41,
      "statuses": [
        { "status": 500, "count": 28 },
        { "status": 429, "count": 13 }
      ]
    }
  ],
  "total": 14,
  "has_more": true,
  "public_api": true
}
